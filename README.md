This project is a simple implementation of a digit classification model using the MNIST dataset. It uses scikit-learn to train a machine learning model capable of recognizing handwritten digits (0–9) from 28x28 grayscale images.

📊 Dataset
Source: MNIST - OpenML

70,000 images: 60,000 for training, 10,000 for testing

Each image is 28x28 pixels (784 features), grayscale

📦 Features
Loads and visualizes random handwritten digit images

Normalizes pixel values for better model performance

Splits the dataset into training and test sets

Trains and evaluates a classifier

Calculates metrics: Accuracy, Precision, Recall, F1-Score

Displays a confusion matrix heatmap

🛠 Technologies Used
Python

scikit-learn

NumPy

Matplotlib & Seaborn
